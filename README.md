# GATE Civil Tracker

A free web app I built to help GATE Civil Engineering students track their preparation in one place.

🌐 https://gateciviltracker.com

### What it includes

* GATE CE syllabus tracking
* PYQ, test and mock tracking
* Revision and study-hour tracking
* Achievements and streaks
* Local progress saving
* Export & import

Built with **Astro, JavaScript, HTML and CSS**.
